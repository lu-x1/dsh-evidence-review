# 本轮改动记录

## S1：核对器侧的轻量状态表

实现冻结提交：`e2e0272`。比较对象仍是冻结0.3.0核对器；生产默认版本、主Agent提示词及文件不改动。

| 项目 | 原版R0 | 本轮S |
| --- | --- | --- |
| 模型、原前缀、工具、核对期限 | 官方Flash/high，原设置 | 相同 |
| 用户原文 | 原完整前缀及来源索引 | 保留，新增消息明确标出 |
| 上次核对的公开解释 | 下一次不专门呈现 | 附来源保存为暂定解释 |
| 已发现的问题 | 不在独立状态中承接 | 保留问题及原文出处，后续重新核验 |
| 修复判断 | 当前核对结果 | 可附修复/过期/未解决提议，程序不自动采信 |
| 单独提取契约的调用 | 无 | 无 |
| 给主Agent的额外状态 | 无 | 无；第一轮仅做影子核对 |

S也增加了通用核对说明：先处理当前问题和后续用户变化；追溯指标的原定义及输入；旧的“正常”判断不是正确性的证明；其他疑点未查清不能抵消已确认冲突。没有写入NFL、水质或Netflix的目标数值、答案、数据列或人工规则。

因此本轮比较的是整个S包，不能把差异单独归因于状态记忆。第一节点没有旧状态，第二节点才有跨核对承接。只保存来源与模型说法，尚不能保证所有依赖都被发现，也不是一套完备的动态契约执行系统。

本地检查11项通过，覆盖：来源修改或跨任务混入拒绝且不部分写入、用户变化追加保留、模型解释不变为权威、空修复承诺不关闭问题、有来源的修复仍只作提议、sidecar异常不抹掉有效核对、原前缀及参数不变、资源契约不可变化。
